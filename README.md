# Machinist Assistant | دستیار تراشکار

دستیار آفلاین محاسباتی و اطلاعاتی برای تراشکاران و اپراتورهای ماشین‌کاری صنعتی.
An offline calculation and reference helper for industrial machinists.

## امکانات | Features

**محاسبات (Calculators)**
- تراش (Turning): دور موتور از سرعت برش، سرعت پیشروی، نرخ برداشت فلز، توان برش و موتور، زمان ماشین‌کاری
- فرزکاری (Milling): دور اسپیندل، فید میز بر اساس تعداد لبه، برداشت فلز و زمان با محاسبه مسیر ورود ابزار
- سوراخ‌کاری (Drilling): دور، فید پیشنهادی خودکار، برداشت فلز، زمان + هشدار سوراخ عمیق (Peck)
- رزوه و تاپ‌زنی (Tapping): سایز مته تراش از جدول رزوه‌های متریک یا محاسبه دستی D−P، نزدیک‌ترین مته استاندارد و دور تاپ‌زنی

**ابزارهای کمکی (Tools)**
- مبدل واحدها: طول، سرعت برش، فید، توان، گشتاور، جرم، زاویه و دما
- وزن قطعه: میل‌گرد، لوله، ورق/بلوک و شش‌گرد با چگالی ۱۱ ماده

**جداول مرجع (Reference Tables)**
- رزوه متریک ISO: درشت M1 تا M68 + ریزهای رایج با مته تراش و جستجو
- سرعت برش ۱۳ ماده با HSS و کارباید + فید پیشنهادی
- انطباق‌های ISO 286 (H7/g6، H7/k6، H7/n6، H7/p6، H8/f7، H7/e7، H7/h6) برای ۱۰ محدوده قطر
- جدول مته‌ها: اینچی کسری 1/64 تا 1" + متریک 0.3 تا 20 mm با جستجو

**سایر**
- دوزبانه: فارسی و انگلیسی (تغییر از منوی صفحه اصلی)
- دو تم تیره/روشن (تغییر از منوی صفحه اصلی)
- راهنمای آموزشی فرمول‌ها به هر دو زبان
- کاملاً آفلاین، بدون هیچ مجوز دسترسی

## دانلود فایل APK از گیت‌هاب (بدون نصب اندروید استودیو)

### روش ۱: ساخت خودکار با GitHub Actions

1. یک ریپازیتوری جدید در GitHub بسازید (مثلاً `machinist-assistant`).
2. کدهای این پروژه را در ریپو قرار دهید:

   ```bash
   git init
   git add .
   git commit -m "Machinist Assistant v1.0.0"
   git branch -M main
   git remote add origin https://github.com/USERNAME/machinist-assistant.git
   git push -u origin main
   ```

3. در گیت‌هاب به تب **Actions** بروید. با اولین push، ورک‌فلو `Build Android APK` اجرا می‌شود
   (اگر اجرا نشد: Actions را وارد کنید، ورک‌فلو را انتخاب و دکمه **Run workflow** را بزنید).
4. پس از سبز شدن build، وارد همان اجرا شوید و در بخش **Artifacts** یکی از دو فایل را دانلود کنید:
   - `MachinistAssistant-release-apk` (توصیه‌شده)
   - `MachinistAssistant-debug-apk`
5. فایل zip دانلودی را باز کنید، APK را به گوشی منتقل و نصب کنید
   (برای نصب باید «اجازه نصب از منابع ناشناس» را برای مرورگر/فایل‌منیجر فعال کنید).

### روش ۲: انتشار در بخش Releases

با هر تگ که push کنید، فایل‌های APK به صورت رسمی در بخش **Releases** ریپو منتشر می‌شوند:

```bash
git tag v1.0.0
git push origin v1.0.0
```

سپس در صفحه ریپو، بخش Releases را باز کنید و APK را دانلود کنید.

## ساخت محلی (اختیاری)

1. آخرین نسخه **Android Studio** را نصب کنید.
2. از منوی File گزینه Open را بزنید و پوشه پروژه را باز کنید.
3. پس از همگام‌سازی Gradle، از منوی Build گزینه **Build Bundle(s) / APK(s) → Build APK(s)** را اجرا کنید.
4. خروجی در `app/build/outputs/apk/` قرار می‌گیرد.

## ساختار پروژه

```
app/src/main/
  java/com/machinist/assistant/
    MainActivity.kt          صفحه اصلی (خانه)
    GuideActivity.kt         راهنمای فرمول‌ها
    MachinistApp.kt          زبان/تم پیش‌فرض
    calc/                    ماشین‌حساب‌ها (تراش، فرز، مته، تاپ، مبدل، وزن)
    tables/                  جداول (رزوه، سرعت برش، انطباق، مته)
    data/                    داده‌های مرجع
    ui/                      آداپترها
    util/                    ابزارهای کمکی
  res/
    layout/                  لی‌آوت‌ها
    values/                  رشته‌های انگلیسی، رنگ، تم
    values-fa/               رشته‌های فارسی
  AndroidManifest.xml
.github/workflows/android.yml   ساخت خودکار APK
```

## یادداشت فنی

- حداقل اندروید: ۷.۰ (API 24) — هدف: اندروید ۱۴ (API 34)
- Kotlin + XML + Material 3 — بدون کتابخانه خارجی غیر از AndroidX/Material
- نسخه release فعلاً با کلید debug امضا می‌شود تا بدون تنظیمات اضافی قابل نصب باشد؛
  برای انتشار در Google Play تنظیمات امضا (keystore) را در `app/build.gradle.kts` اضافه کنید.
- مقادیر سرعت برش و فید، راهنمای کارگاهی هستند؛ همیشه با کاتالوگ سازنده ابزار تطبیق دهید.
